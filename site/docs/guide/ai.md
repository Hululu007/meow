# AI 助手

客户端内置的对话助手。它不模拟点击界面，而是直接查客户端的搜索、片源健康、播放地址、日志与缓存，再把结果说成一句话。

它能帮你**找到并播起来**，也能在出错时**指出原因**；但起播、下载这类动作，最后一下始终由你点。

## 打开它

| 入口 | 在哪 | 适合 |
|---|---|---|
| 悬浮面板 | 多数页面右下角的星标按钮，或按 `Ctrl+K`（Mac 为 `Cmd+K`） | 边看边问，不离开当前页 |
| 独立页 | 顶栏「AI」；手机上点底部导航中间的「AI」 | 回答长、要反复翻，或电视上用遥控器 |

- 播放页、直播页不显示悬浮按钮（避免挡住播放控件）；在这两页想问，点顶栏「AI」。
- 浮层右上「全屏」切到独立页，**会话内容不会丢**；独立页右上「设置」跳到设置页（再点左侧「AI」分区就是模型配置）。
- 标题旁只有两种状态：**已启用模型** 或 **仅本地判断**。

![AI 助手独立页：标题旁显示「仅本地判断」，右上角「设置」跳到设置页](/screenshots/ai-panel.png)

## 它能查什么

回答上方那行「已查：…」是它这次调用过的能力名，多数是中文，少数会直接显示 `meow_` 开头的工具标识。不用记，看到能对上即可。

### 找片与播放

| 「已查」里显示 | 它去做什么 | 你可以这样问 |
|---|---|---|
| 搜索 | 按片名跨源搜，列出可播来源 | 「庆余年」「找流浪地球」 |
| 取播放地址 | 选线路、挑集数，拿到可播地址；内部自动换线 | 「播庆余年第一集」「就播它」 |
| 缓存 | 查已缓存哪几部、下到第几集、占多少空间 | 「我缓存了什么」「下完没」 |
| 缓存 | 解析可下载直链、弹确认卡（不直接下载） | 「帮我缓存这部」「缓存第 3 集」 |

### 排障与状态

| 「已查」里显示 | 它去做什么 | 你可以这样问 |
|---|---|---|
| 诊断 | 解释播不了：读播放器状态、网络失败与后端日志 | 「为什么播不了」「黑屏」 |
| 日志 | 翻后端日志，可按级别、模块、时间窗收窄 | 「刚才报什么错」 |
| 源健康 | 哪些源降级或停用、失败原因 | 「哪些源挂了」 |
| 弹幕 | 查某部片的弹幕源 | 「这部为什么没弹幕」 |
| 直播 | 直播频道数与坏台情况 | 「直播能看吗」 |
| 片库 | 本地 / NAS 片库概览 | 「我本地有什么片」 |

### 三件容易搞混的事

- **建立上下文**是每轮对话的开场摸底（版本、源数、哪些源降级、最近有没有异常），不用你问；它在「已查」里的名字是「建立上下文」。
- 两个都叫**缓存**：一个是查进度，一个是准备下载。
- 只描述类型（「下饭的喜剧」）不会触发搜索——源站是关键词搜，不是语义检索；配了模型它会先反问你要哪部。

## 怎么问

一句话说一件事，片名越完整越准。下面这些说法都能直接照抄。

| 你想干的事 | 直接说 |
|---|---|
| 找片 | 「庆余年」「找流浪地球」 |
| 指定集数播放 | 「播放庆余年第一季第 2 集」 |
| 问续集、问口碑 | 「庆余年有没有第二季」 |
| 说播放故障 | 「为什么播不了」「一直转圈」 |
| 查状态 | 「哪些源挂了」「我缓存了什么」 |

- 集数写「第 3 集」「第三集」「EP3」都认；不写就取第一条线路的第一集。
- 追问不用重复片名：「就播它」「换个源」「还有别的吗」会沿用上一轮结果。
- 一次只问一件事。太长的描述拆开问，比堆在一句里更容易得到准答案。
- 输入框一次最多 100 字。

## 斜杠命令

在输入框打 `/` 会列出可直接用的命令：上下键选、Enter 填充、Esc 关掉。命令**不经过模型**，所以没配模型也能用，也不存在"AI 猜错"的环节。

![输入框打 / 弹出命令列表：每条都标着参数格式，选中后下方给出示例（如 /搜索 庆余年）](/screenshots/ai-slash.png)

| 命令 | 例子 | 说明 |
|---|---|---|
| `/搜索` | `/搜索 庆余年` | 跨源搜片，列影片卡片 |
| `/播放` | `/播放 庆余年 第3集` | 直接取可播地址；不写片名就用上一轮那部 |
| `/缓存` | `/缓存 庆余年` | 先解析直链并弹确认卡；点了才下载 |
| `/诊断` | `/诊断` | 为什么播不了，本地规则给结论 |
| `/日志` | `/日志 warn`、`/日志 error 播放` | 级别可写 info/warn/error，其余词当关键词 |

- 命令名支持英文缩写：`/s` `/p` `/c` `/d` `/l`；`/日志` 里加 `tag:req` 可按模块精确筛。
- 打完命令名加一个空格，候选列表会收起（继续打参数即可）。
- 打错的命令（如 `/xyz`）不会被当成命令，会按普通一句话处理。
- 电视上用遥控器打不出 `/`，点输入框左边的 `/` 按钮，再用方向键选。

## 回答里能点什么

回答不只是文字。看到下面这些，点就对了。

| 看到 | 点哪里 | 结果 |
|---|---|---|
| 影片卡片 | 「▶ 详情」 | 进详情页选线路播放；AI 不会替你直接起播 |
| 同一部片有多个来源 | 卡片下方的源名 | 用那个源打开 |
| 缓存确认卡 | 「开始下载」/「不用了」 | 入队，去「片库 → 我的缓存」看进度；不点就不下载 |
| 「运行日志」「设置」「片库」「历史」「收藏」 | 对应按钮 | 直接跳过去 |
| 面板右上 | 「全屏」「关闭」（悬浮面板）/「设置」（独立页）/「清空」 | 切到独立页 / 关掉面板 / 去模型配置 / 清空会话 |

「已查：…」那一行是它这次查了什么；后面带（失败）说明那一步没成。跳转按钮只在没有影片卡片时出现——有卡片时你的下一步是点卡片。

## 配模型

设置 →「AI」，三步：勾「启用」→ 选一个「快速填入」或手填地址与模型 → 点「测试连接」。

| 项 | 怎么填 |
|---|---|
| 启用 | 总开关；关掉后只剩规则诊断与本地搜索 |
| 接口地址 | OpenAI 兼容地址，一般以 `/v1` 结尾 |
| 模型 | 模型名，可自填，不限定厂商 |
| API Key | 必填；留空时仍按「仅本地判断」处理。只存本机，不进备份 |
| 上下文 | 保留最近几轮问答，0–10，默认 5；0 表示不带历史 |
| 快速填入 | 自建网关、DeepSeek 官方、本地 Ollama 三档；只帮你填地址和模型名 |

测试按钮要地址和 Key 都有值才能点。看到「连通（模型回复：…）」才算通，失败原因会写在按钮右边。

::: tip Web / TV 不是浏览器直连
浏览器直连模型会被跨域拦，所以 Web / TV 由后端转发到你填的地址。在设置里打开「启用」时，后端转发开关会一起打开，不用再找第二个开关。
:::

选模型时确认它支持工具调用：不会调用工具的模型只能聊天，查不到片源和日志。

配了模型，你的原话和它查到的片段会发给你填的那个地址，模型服务商能看到这些内容；没配模型则只有客户端和自己的后端在动。API Key 只存本机，不进备份。日志片段可能带源站域名或 token，用第三方模型前自己判断是否接受。

## 不配模型也能用

不填模型时，标题旁显示「仅本地判断」。这部分不花 token，也不经过模型服务商。

| 能力 | 还能用吗 | 怎么用 |
|---|---|---|
| 播放失败诊断 | 能 | `/诊断`，或播放页出错时的错误页；只是少一句模型写的解释 |
| 按片名搜索 | 能 | `/搜索 片名`，最多列 6 部，点「详情」 |
| 指定集数取地址 | 能 | `/播放 片名 第3集`，或直接说「播放 X 第 3 集」 |
| 缓存（离线看） | 能 | `/缓存 片名`，解析后弹确认卡，点了才下载 |
| 查后端日志 | 能 | `/日志 warn`、`/日志 error 播放` |
| 「就播它」 | 能 | 上一轮搜到片之后，直接回「就播它」就取地址 |
| 「换个源」「还有别的吗」 | 不能 | 要模型理解上下文才知道该换哪部 |
| 源健康、直播、片库、弹幕 | 不能 | 还没有对应命令，这几项要配模型 |

没配模型时，**优先用斜杠命令**：命令会把片名和集数拆开处理；自然语言那句则整句当关键词搜——「庆余年」能搜到，「找流浪地球」多半搜不到。

所以：**播放失败先看播放页的错误页**，那里的规则诊断不需要模型，具体排查见[播放与弹幕](/guide/playback)；面板更适合配好模型后再问「为什么」。

## 出问题先看什么

先读红字，它已经说明停在哪一步；再决定重问还是去看日志。

| 看到 | 含义 | 下一步 |
|---|---|---|
| 「分析超时了」 | 这一轮模型没按时回来 | 再发一次；仍超时就点「运行日志」，或换个模型 |
| 「AI 反复尝试同一步」 | 同一动作被重复调用，已主动停下 | 换个说法，补上片名或集数 |
| 「试了 8 轮还没搞定」 | 单次任务最多 8 步 | 拆成两个问题问，或自己点更快 |
| 「没有搜到匹配的影片」 | 关键词不像片名，或源里确实没有 | 换个片名；也可去搜索页手动搜 |
| 「已查」里某一步带（失败） | 那一步没成功 | 按回答里的入口去日志，或换说法 |
| 标签是「仅本地判断」 | 模型没启用或没填全 | 设置 →「AI」 |

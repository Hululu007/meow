# AI 助手

客户端内置一个对话式助手：能搜片、看详情、换线路、翻后端日志，也能在播放失败时用人话解释原因。**不配模型也能用其中一部分**。

## 两个入口

| 入口 | 位置 | 适合 |
|---|---|---|
| **悬浮面板** | 任意页面右下角 | 边看边问，不打断当前页面 |
| **AI 助手页** | 侧边栏 → AI 助手 | TV / 手机上方向键滚动更顺，对话区长 |

![AI 助手面板：未配置模型时标签显示「仅本地判断」](/screenshots/ai-panel.png)

*没配模型时标题旁会标「仅本地判断」——规则诊断照常工作*

全屏播放时悬浮面板会自动隐藏，退出全屏后回来。

## 它能做什么

### 1. 诊断解释（不需要模型）

播放失败、黑屏、一直转圈时，客户端本身有一套**规则诊断**：按播放器事件判断是网络、
源站、编码还是跨域问题，给出结论。

这部分**零 LLM 依赖**，没配模型也照常工作，只是解释会短一些。

### 2. 对话与工具调用（需要模型）

配好模型后，助手可以调用客户端里的语义工具，比如：

- 搜索片名、看详情、取播放地址
- 查看站点健康、直播源状态
- 读后端日志、缓存状态
- 换线路重试

它不是"AI 点界面"——工具直接调客户端内部接口，比模拟点击稳。

### 3. 排障问答

可以直接问「刚才报什么错」，它会真的去翻日志，而不是编答案。

## 怎么配模型

设置 →「AI 助手」：

| 项 | 说明 |
|---|---|
| 启用 | 总开关，关掉后只剩规则诊断 |
| 预设 | 常见服务商一键填 baseUrl / model |
| `baseUrl` | OpenAI 兼容地址，如 `https://api.example.com/v1` |
| `apiKey` | 你从服务商拿的 key |
| `model` | 模型名 |
| `maxTokens` | 单次回复上限 |
| `historyRounds` | 带多少轮历史（0–10），越大越贵 |

填完点「测试」确认连通。

::: tip Web / TV 走的是后端转发
浏览器里直连模型会跨域，所以 Web 与 TV 通过后端 `/api/llm/relay` 转发。
转发只是转发到**你自己配的地址**，项目没有中转服务器。

PC 设置页会把「启用」同步到后端的 `llmRelay`，避免出现两个开关互相打架。
:::

## 隐私

- 对话内容会发给你配置的模型服务商，**不经过本项目**
- 工具调用的结果（片名、日志片段）只在你本机与本机后端之间流动
- 不配模型时，所有请求都不出本机
- 不会写进任何云端账号

::: warning 日志里可能有敏感信息
助手读日志时可能把源站域名、token 一起带进上下文。如果用的是第三方模型服务，
自己判断是否接受。
:::

## 常见问题

### 总是超时

两个最常见的真因：

1. **模型不支持 tool calling**：助手需要函数调用能力，纯补全模型会一直卡在工具往返
2. **baseUrl 少了 `/v1`** 或填了带路径的完整接口地址

### 配了模型但回答很短 / 不调工具

检查 `maxTokens` 是否太小，以及模型是否在服务商侧启用了函数调用。

### TV 上输入不方便

用「AI 助手」独立页，而不是悬浮面板；也可以先在手机上配好模型，配置会跟随同一后端。

### 关掉 AI 会怎样

规则诊断、搜索、播放都不受影响。AI 只是一个可选的解释层。

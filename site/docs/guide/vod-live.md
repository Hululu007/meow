# 点播与直播

这一页讲两条「从打开到出画面」的路径：用导入的源点播，和用 IPTV 看直播。播放器操作、弹幕与投屏在 [播放与弹幕](/guide/playback)；自己的文件与离线缓存在 [片库与缓存](/guide/library)；想让 AI 帮你找片看 [AI 助手](/guide/ai)。

## 首页：先按分类逛

打开客户端先落在首页。顶部一排分类胶囊是当前源给的，默认选中第一个；下面是这一类的海报墙，顺序就是源站给的，滚到底自动加载下一页。

| 想做的事 | 点哪里 |
|---|---|
| 换分类 | 顶部分类胶囊 |
| 换一个源 | 左上角站点名，弹出站点列表 |
| 搜具体片名 | 顶栏搜索框，回车进搜索页 |

分类的名字各源差别很大（有的叫「热播剧集」，有的叫「内地」），以实际界面为准。源如果没给分类，首页直接展示它给的推荐列表。翻页失败时海报墙底部会出现一行「下一页加载失败，点此重试」。

## 搜索：跨所有源找同一部片

搜索页有两种状态。没有关键词时是**空闲态**：左边热播榜（剧集 / 电影 / 综艺三档），右边最近搜索（最多 12 个词，可以单个删或清空）。点榜上的一条或一个历史词，就用这个词直接开搜；热播榜拉不到就留空，不影响搜索。

输入片名回车进入**结果态**，边搜边出：每半秒刷新一次进度，结果上方显示「x/y 个源已返回」。同一部片在几个源都有，就并列几张卡片，卡片上标着它来自哪个源；源多于一个时，宽屏左边多一列按源筛选（手机上是结果上方一排胶囊），每个源后面带命中条数。

| 情况 | 默认行为 |
|---|---|
| 单轮上限 | 最多等 30 秒，到点用已有结果 |
| 提前收尾 | 已有结果、且大多数源都回来之后，连续约 3.5 秒没有新源返回就收尾 |
| 命中缓存 | 有结果 2 小时；空结果 3 分钟；失败 60 秒 |
| 点「重新搜索」 | 绕过缓存重跑，约 10–30 秒 |

搜索范围可以在顶部「全部站点 / 仅当前站点」之间切，切换后立刻重跑；「仅当前站点」搜不到会直接告诉你这个站没有结果。缓存时长在 设置 → 搜索与源 → 结果缓存 里改（还能一键清空），改完立即生效。

结果里可能出现「已滤掉 N 条噪音」或「N 条噪音已沉底」，那是 设置 → 搜索与源 → 噪音过滤 的效果——命中词表的条目要么不显示，要么排到最后，想看到它们就把词表清空。

电视上按返回键先回到空闲态（最近搜索还在），再按一次才退出搜索页。

## 详情页：选线路、选集、开始播

点搜索结果里的卡片，进的是**那张卡所属源**的详情页；卡片上的源标记和详情页年份那一排的「来源 xx」指的是同一个源。

| 区域 | 内容 |
|---|---|
| 播放源 | 这个源自己的线路，按钮后面的数字是该线路的集数；线路可能有多套（不同清晰度或版本），集数不一定相同 |
| 剧集 | 当前线路的集数，点任意一集开始播；「立即播放」等于当前线路第 1 集 |
| 主按钮 | 看过的话变成「继续看 第 N 集」，旁边另给「从第 1 集看」 |

上次在这部片用过的线路会被记住，下次进详情页先选中它。点某一集进去后，整条线路的集数一起带过去，播完自动接下一集；选集、换线、倍速、字幕和弹幕见 [播放与弹幕](/guide/playback)。

### 没有播放源时怎么换源

有些源只给简介和海报，不给播放地址。这时「立即播放」是灰的，右栏给一个「在其它源搜索「片名」」的按钮，点一下带着片名去聚合搜索页自己挑别的源。

如果连详情都拿不到（页面一整块空白），会自动带着片名跳到搜索结果，不用自己返回重搜。

## 直播：频道从哪来

直播页是聚合视图，频道有两个来源：

| 来源 | 是什么 | 现状 |
|---|---|---|
| 站点直播表 | 源站自己提供的频道分组 | 多数源没提供，通常是空的 |
| IPTV 播放列表 | 一份 m3u / txt 频道清单 | 实际在用的就是这一路 |

IPTV 播放列表的地址有三处来源：源包或配置里带进来的、客户端内置的两条、你自己添加的。

内置两条开箱就在列表里：

| 名称 | 是什么 |
|---|---|
| 公共直播源（每日更新） | 综合频道多，央视、卫视、地方台这些，源站自称每天更新 |
| iptv-org 中文台 | 中文语言包，含港澳台与海外中文台 |

两条都是第三方公共源，只是索引别人家的流、不托管内容，版权状况不明；源站不稳时可能打不开。可以逐条删掉换成自己的，删了不会自己回来；删错了点「恢复内置源」。

## 添加与维护直播源

![设置页「搜索与源」区块的直播源一栏：内置两条公共源的说明、多源合并显示开关、添加地址的一行，以及快捷添加 iptv-org 国家](/screenshots/settings-source.png)

自己添加走 设置 → 直播源 里的「名字（可留空）+ 地址」；只有把所有源删光、直播页进入空态时，页面上才会出现一个同样的输入框。地址填 `http(s)` 开头的 m3u 或 txt，保存前会先真拉一遍，解析不出频道就不保存。设置页还有一组「快捷添加 iptv-org」按钮，按国家/地区加，省得自己抄地址。

每条源都能点「测试」，结果显示「可用 · N 个台 · X 天前更新」，超过一周没更新会标「已停更，考虑换源」——判断一条源好不好用，看这个比看名字准。

## 换台与切线路

从顶栏点「直播」进直播页（窄屏在「更多」菜单里）。整页就是画面，直接播上次看的台；第一次进来播当前列表第一个台。

| 操作 | 遥控器 / 键盘 | 竖屏底栏 |
|---|---|---|
| 换台 | ↑ / ↓，到头会绕回另一端 | 上一个 / 下一个 |
| 切线路 | ← / → | 线路按钮（多线路时才有） |
| 呼出频道面板 | OK | 「频道」 |
| 关面板 / 退全屏 / 离开 | 返回键逐层退 | 系统返回；全屏时左上角也有返回 |

频道面板是「分类 - 台」左右两栏：↑↓ 在当前列移动，←→ 换列，OK 在台列选台（在分类列则进入该分类）。多源时左列上方能换源，左列标题那行有「刷新」。

横屏（电视、投影、桌面宽屏）不渲染底栏，方向键全部用于换台和切线路，单击画面等同 OK；竖屏单击是暂停 / 继续，双击切全屏。

## 坏台与坏线：先换线，再换台

换台后 6 秒还没有画面，就判定这个台有问题，处理顺序是先换线、再换台：

1. 同一个台还有别的线路 → 自动切下一条，画面中央提示「换线路 2/6 · 频道名」。
2. 这个台的线路全部试完 → 才跳到下一个台，提示「跳过坏台 · 名字 (第几个/共几个)」。
3. 一轮最多连跳 5 个台，还不行就停下报错（多半是网络或播放列表过期了），不会一直刷源。

开着多源合并时（设置 → 直播源里可关），同一个台的线路会合在一起，面板里显示「N 线」，可换的线路更多。

想手动重试当前台，点竖屏底栏的「重播」；横屏直接 ←→ 换线路，或呼出面板换台。

## 节目单（EPG）

当前不做节目单。频道面板里只有分类和台名，看不到「现在播什么 / 下一档是什么」；源包里带的节目单地址目前也不解析。

公共 EPG 源时效性太差，暂时不做，以频道画面里的实际内容为准。

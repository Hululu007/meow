# 常见问题

按症状查找。每条都给出「先查什么」而不是笼统的「检查网络」。

## 安装与启动

### 装完打开是空白 / 一直「后端未连接」

PC 端这是**设计如此**：安装包不含后端插件。去「设置 → 本机插件」配置插件源并下载
「影视后端」。装完前端会自动恢复，不用重启。

Web 端检查 `web` 容器能否连到 `apiserver`：页面能开但接口 503，通常是
`MEOW_APISERVER` 指向的容器名解析不到。

### fnOS 页面白屏

必须从应用中心网关入口打开。子路径部署对前端 `base` 有要求，
直接拼端口访问可能白屏。

### PC 应用装完版本不对 / 升级后还是旧版

先确认每个插件目录里 `manifest.json` 的版本号；`enabled.json` 只记录启停开关（`{id: true/false}`），不含路径。
应用本体与插件版本是独立演进的，两者不必一致。

## 源与配置

### 导入提示成功，但站点全是红的

按命中率排查：

1. **顶层 `spider` 不是 dex**：Fongmi/TV 要 dex（ZIP 内含 `classes.dex`）；
   JVM 会自动转，但 Android 不会
2. **站点既没有 `jar`，顶层 `spider` 也不可用**：TV 会跳过这类 `csp_` 站
3. **配置里的地址是 `127.0.0.1`**：在电视/手机/容器里，它指设备自己
4. **jar 下载不到**：`spider` 的 MD5 不匹配会直接拒绝加载
5. **缺少运行时**：`.js` 源需要 drpy，没起就是「不可用」

### 报 `ClassNotFoundException` / `NoClassDefFoundError`

- `ClassNotFoundException`：jar 里没有这个类，或 jar 没被加载（TV 常见于格式不对）
- `NoClassDefFoundError`：类在但依赖缺；或旧 JVM 拿到了未转换的 dex 源包

猫窝 JVM 当前会在导入期把 dex 转成 class；旧版 JVM 仍然需要
`config.jvm.json`（顶层 `spider` 指向 class jar）。迁移到新源包时，记得勾选
「用这份配置的顶层 spider 覆盖本地」，否则本机还留着旧 jar 地址。

### 追加导入了新仓，旧站点消失了

「替换」模式会整表换掉。日常增量导入请选「追加」，同名站点冲突再选保留/替换/都留。

### 源站突然全挂了

大概率是上游整条失效，不是客户端问题。换源包或等上游恢复。
源站时效性很强，这是这类客户端的固有特性。

## 播放

### 能搜到、点进去没有线路

这个源只有元数据没有播放源。用详情页底部的「在其它源搜索《片名》」换源。

### 点播放一直转圈 / 黑屏

1. 换线路（播放页「线路」或左右键）
2. 换源（详情页选别的站）
3. 看是不是需要 WebView 解析的源（`type: 0`）：**Web 后端没有 WebView，不支持**
4. 检查后端日志里的 `playError` / `hopError`

### 播几分钟就断

源站播放地址常绑客户端 IP 且几分钟过期。重新进详情页取新地址，
或换一个更稳的源。

### 有声音没画面

编码不被当前播放器支持。播放失败页会给「换个画质」出口；
PC / TV 上优先尝试原生解码，Web 端受浏览器限制。

### 全屏后切集退出了全屏

浏览器要求全屏必须由用户手势触发。换集时全屏元素离开 DOM 会被强制退出，
之后只能进伪全屏。桌面端已在应用层处理，浏览器端属平台限制。

### 倍速一高就卡

1.25x 以上会按带宽自动压码率；压到最低仍跟不上会临时回 1x 并提示。
这是保护行为，不是 bug。

## 弹幕

### 弹幕一条都没有

1. 这一集可能确实没有弹幕（冷门片常见）
2. 搜一下片名手动选源
3. 弹幕服务不可用时，内置直连仍然工作；两者都空就是真没有

### 弹幕不动 / 整屏消失又重打

缓冲时弹幕会暂停，恢复后继续。如果时间在走弹幕不动，检查设置里的
「弹幕 API 优先」是否指向了一个不可达的服务，导致请求一直挂起。

### 装了弹幕插件还是只有一种来源

`policy.json` 里的 `danmakuApi` 可能被之前手填的地址占着。清空它并**重启插件 / 应用**——
插件启动时才会自动回填。Docker 部署下环境变量 `MEOW_DANMAKU_API` 优先级高于 policy.json，
清空 policy 无效，要改 `.env`。

## 网络与端口

### 手机 / 电视访问不了后端

按端的默认监听不一样：

- **Docker**：宿主端口默认只绑 `127.0.0.1`（`APISERVER_BIND`），要局域网访问改成 `0.0.0.0`
- **PC 后端**：默认监听 `0.0.0.0`（可用 `MEOW_BIND=127.0.0.1` 收紧）——同网段本来就能访问，没设令牌时人人能改配置

对局域网开放时都要：

1. 设置 `MEOW_AUTH_TOKEN`，否则同网段任何人都能改你的配置
2. 确认防火墙放行

### 端口被占用

- PC 后端：从 9979 开始自动协商到 9985，不用手填
- Docker：改 `.env` 里的 `APISERVER_PORT` / `WEB_PORT`
- fnOS：安装向导里改，范围 1024–65535

### 跨域 / 403

`MEOW_CORS` 默认 `*`。改成白名单后要确认访问来源在列表里，
否则第一个 POST 就会 403，页面表现为空白。

## TV 专项

### 遥控器移不到地址输入框

个别遥控器在纯本机形态下无法把焦点移到输入框。改用扫码推送配置，
或先切到后端模式在手机/电脑上完成配置。

### 投影仪上聚合搜索闪退

32 位低端设备（armeabi-v7a）的 ART 在并发分配下有已知崩溃。
属端上资源限制；客户端已做缓解（限并发）但没有根治，见 [已知限制](/reference/limits)。

## 还是解决不了

提 Issue 时附上：

- 端类型与版本号（设置页底部）
- 具体操作步骤
- 后端日志片段（Web：`docker compose logs apiserver`；PC：插件日志）
- 如果是源的问题，说明是哪个形态（jar / drpy / CMS）以及报错文本

::: warning 不要在 Issue 里贴源包
源包与站点配置可能涉及第三方授权，贴出来既帮不上排查，也可能带来合规风险。
提供报错文本与结构（不要贴真实域名与 token）就够了。
:::

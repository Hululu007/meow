# 片库与缓存

这一页讲两件互不相干的事：**自己的文件**（本地片库）和**已经下到后端的片子**（我的缓存）。两件事都在顶部导航的「片库」里，用页签切换。

在线源的搜索、点播与直播见 [点播与直播](/guide/vod-live)；播放器、字幕与弹幕见 [播放与弹幕](/guide/playback)；想让 AI 帮你解释播放失败见 [AI 助手](/guide/ai)。

## 打开「片库」

顶部导航点「片库」进来。页面顶部两个页签：**本地片库** 和 **我的缓存**；右上角的「添加片库」和「刷新」只在本地片库页签显示。

![片库页空态：上方是「本地片库 / 我的缓存」页签，右上角是「添加片库」和「刷新」，中间提示还没配置片库](/screenshots/library-empty.png)

第一次进来是空态，页面会提示还没配置片库，从右上角「添加片库」开始。

## 添加第一个片库

### 选存盘类型

| 类型 | 地址怎么写 | 适合 |
|---|---|---|
| Webdav | `http://192.168.1.19:5005/` | NAS、网盘；群晖加 `/dav`，Nextcloud 加 `/remote.php/dav/files/用户名` |
| SMB | `smb://192.168.1.19/视频` | Windows 共享、NAS 共享；地址要写到共享名 |
| 本地目录 | `D:/影视` 或 `/mnt/media` | 后端所在机器上的硬盘 |

「本地目录」指**后端所在机器**上的路径，不是手机或电视上的路径。类型列表里还有一项「Alist网页」，它标着「（下版）」、当前不可选；但 Alist 自带 WebDAV，选「Webdav」填 `http://主机:5244/dav` 就能用。

### 填字段

| 字段 | 怎么填 |
|---|---|
| 名称 | 片库页上显示的名字；留空会用地址 |
| 地址 | 服务入口，见上表 |
| 根路径 | 要进的子目录，如 `/视频`；留空 = 地址根 |
| 用户名 / 密码 | WebDAV、SMB 按需填；本地目录没有这两项 |
| 域 | 只有 SMB 有；域账号填这里，用户名只写账号名 |

填完先点「测试连接」，成功会提示可以连接（WebDAV 的「根目录 N 项」恒为 1，是协议只回目录自身的限制，不代表路径错）；再点「保存」。密码存在后端的数据目录，不会回显到页面。

::: tip 先确认地址能打开
地址填到目录级，不要填到具体文件。**WebDAV** 可以在浏览器里打开验证（能出目录列表或要求登录就基本对了）；SMB 与本地目录浏览器打不开，跳过这步。报「连接失败」时九成是路径少了一层、端口不对或账号不对。
:::

### 之后想改配置

保存后根层「已配置」那一行就是它，可以编辑或删除。编辑时不能改类型（要换类型就新建一个），密码框留空表示不改。删除只移除配置，不动 NAS 上的文件。

## 在片库里走动

| 你在哪 | 看到什么 | 点哪里 |
|---|---|---|
| 根层 | 每个库的顶层目录分组、已配置的片库 | 目录卡进下一层；「添加片库」「刷新」在右上角 |
| 目录层 | 子目录和影片海报 | 目录卡继续往下，影片卡进详情 |
| 影片详情 | 海报、年份、集数、体积、选集 | 「立即播放」或直接点集号 |
| 选集 | 集号网格 | 点集号开播；右键下载原文件 |
| 任意层 | 左上角「返回」 | 退一层，标题旁的面包屑显示当前位置 |

一个目录如果本身就是一部剧（至少一半文件带集号、没有子目录），会直接进详情，不再多一层只有一张卡的海报墙。

地址栏会记住当前目录，刷新后还在原地。列不出目录时先看后端是否在跑——NAS 本身可能并没有掉线。

## 让文件名认得出来

根路径下按「分类 / 片名 / 季 / 集」分层，刮削和归组最省心：

```
视频/
├── 电影/教父 (1972)/教父.1972.1080p.mkv
└── 电视剧/毛骗/
    ├── 毛骗S01/S01E01.mkv
    └── 毛骗S02/
```

### 认得的写法

| 文件名 / 目录名 | 认成 |
|---|---|
| `S01E02` | 季 + 集 |
| `E02`、`EP02`、`第3集`、`第3话` | 集 |
| `01 标题`、`01.mp4` | 集 |
| `第1部` | 部（电影合集） |
| `S01`、`Season 2`、`第一季` | 季目录，剧名从上一层取 |
| `19xx`、`20xx` | 年份 |

两条规矩能省掉大部分返工：

- **一个目录里至少一半文件带集号，这个目录就被当成一部剧**，剧名取目录名（`毛骗S01` 会剥成「毛骗」）。所以剧集目录要写剧名，别只写「S01」。
- **年份写进文件名**。只写在文件夹名上不参与匹配；同一部剧的集号写法也要统一，否则容易被拆成多张卡。

## 补上海报

进目录先出文件名，海报随后补，右上角会显示「正在补海报…」。刮削就是按片名匹配海报和年份。

用的名字分两种情况：**剧集用目录名**（文件名里是集号和副标题，搜不出东西）；**单片电影用文件名里的片名 + 年份**（目录名常是中文别名，豆瓣上没有）。

匹配结果会缓存，重复进目录不会反复查外网。详情页能看到当前状态：「已绑定海报」或「未绑定」。

### 匹配错了怎么办

| 操作 | 什么时候用 | 结果 |
|---|---|---|
| 重新搜刮 | 匹配错了，或上次没刮到 | 跳过缓存重查一次，成功 / 失败都有提示 |
| 解除绑定 | 怎么搜都匹配到错的条目 | 移除这张海报，下次进目录重新匹配 |

搜不到时，把文件夹名（剧集）或文件名（电影）改成豆瓣上的正式片名，再点「重新搜刮」。界面没有手填条目 ID 的入口。

::: tip 没海报不一定是命名问题
右上角出现「豆瓣限流，海报稍后自动重试」时，是外网在限流，等几分钟或点「刷新」即可。
:::

目录卡的封面取目录里第一部影视的海报；一路探不到视频的目录保持文件夹图标。电视端会在本机留一份海报副本兜底，详情页里可以「清空本机海报副本」。

## 播一部片：直连与转码

点集号永远先直连；只有真的播不了，播放页才自动转码。

| | 直连 | 转码 |
|---|---|---|
| 起播 | 直接读原文件，快 | 等后端切出首批分片，可边转边看 |
| 拖动 | 直接跳 | 已转出的部分可拖 |
| 画质 | 原画 | 转码后的流 |
| 依赖 | 后端能读到文件 | 后端带 ffmpeg |
| 源文件 | 不改 | 不改，产物写在后端缓存目录 |

转码不是按扩展名预先判断，MKV、H.265 也会先试直连。提示「直连播不了，正在启动转码」时等一会；成功后显示「已转码播放（源文件未改动）」。

后端没有 ffmpeg 时转码会失败。Docker 镜像和 PC 插件版自带；TV 本地网关可能没有，错误页会建议换后端或改用原生播放器。

想留一份原文件：在选集上右键，浏览器按原文件下载（4K 单集可能 1.4–2GB）。触屏设备没有右键，目前拿不到原文件。

## 把片子缓存下来

缓存把正在看的一集（或整季）存到后端，断网也能接着看。入口叫「下载到本机」，实际落在后端的数据目录。

片库里的文件不吃这套缓存（播放页里没有这两个入口），要离线请用上一节的右键下载原文件（触屏端没有右键，暂不支持）。

### 单集与整季

| 范围 | 从哪里点 | 注意 |
|---|---|---|
| 单集 | 播放页「更多」→「下载到本机」 | 同一项显示 缓存中 N% / 已可离线观看 / 缓存失败（重试）；拿不到 http(s) 地址时没有这一项 |
| 整季 | 详情页「剧集」右边「缓存整季」；或播放页「更多」→「下载整季」 | 用当前线路逐集取地址，需要解析器的集会被跳过；结束后报加入 / 跳过几集 |

缓存是后台任务，可以退出页面；进度到「我的缓存」看。

### 看进度与续传

片库页顶部切到「我的缓存」：每部片一张卡，角标是「N/M 集」。

| 位置 | 能做什么 |
|---|---|
| 面板头部 | 总占用与上限、下载中几集、接近上限的提示 |
| 缓存卡片 | 看已下集数 / 总集数；点开进详情 |
| 卡片详情 · 顶部 | 继续观看、暂停下载、删除整剧 |
| 卡片详情 · 选集 | 看每集状态；按状态给出继续下载 / 暂停 / 取消 / 删除本集 |
| 整季下载 | 看每集进度；「重试失败 N 集」 |
| 未下完 | 「全部继续下载」；从第一个缺失分片续，已下的不重下 |

后端重启后，正在下的任务会变成失败并出现在「未下完」，点「继续下载」即可；那一行里的「已有 N 片可复用」就是上次已经下好的部分。

### 离线优先

开播先查本地：这一集已经完整下完时，直接播本地清单，不请求源站，画面上方显示「离线播放（本机缓存）」。

只有完整下完的集才算；下到一半仍会联网。

::: warning Web 部署时缓存不在你手上
缓存放在后端的数据目录。Web 部署时缓存在服务器上，手机断网后访问不到；要真离线，用 PC 端（后端就在本机）或把后端跑在本机。
:::

电视端在卡片详情里还有个「存到U盘」，把已下好的一集导出到 U 盘——那是彻底脱离后端的唯一办法。

### 清理

| 想做的事 | 去哪里 | 说明 |
|---|---|---|
| 删一集 / 整剧 | 我的缓存 → 打开卡片 → 选集 / 删除整剧 | 文件从磁盘移除，不可恢复 |
| 限制总占用 | 设置 → 存储 → 缓存配额 | 填 GB；0 = 不限制 |
| 超限怎么办 | 设置 → 存储 → 超限时 | 自动删最旧 / 只提示不删 |
| 换缓存盘 | 设置 → 存储 → 缓存位置 | 相对数据目录或绝对路径；改后需重启后端 |
| 清弹幕缓存 | 设置 → 存储 → 后端弹幕缓存 | 清过期（30 天）/ 全清；不占视频配额 |

缓存页头部显示实际占用和上限；超过 90% 会标「接近上限」。

## 出问题先看什么

| 现象 | 先看什么 |
|---|---|
| 添加时「连接失败」 | 地址是否到目录级、端口 / 共享名 / 账号；先用浏览器打开 WebDAV 地址 |
| 片库页提示连不上后端 | 后端进程或设置里的后端地址；NAS 本身可能没掉线，起好后点「刷新」 |
| 有文件名、没海报 | 右上角是否「豆瓣限流」；不是就改名后「重新搜刮」 |
| 点集号黑屏 / 报错 | 等自动转码；仍失败看后端有没有 ffmpeg，或换后端 / 用原生播放器 |
| 「我的缓存」是空的 | 是否切到了这个页签；Web 部署时后端是否可达 |
| 缓存被自动删了 | 设置 → 存储 → 缓存配额 / 超限时 |
| 下到一半不动 | 我的缓存 → 看这一集是「下载中」还是「失败」；失败的在「未下完」里点「继续下载」 |

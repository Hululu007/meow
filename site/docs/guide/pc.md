# PC 桌面端

Windows 桌面应用，Tauri 2 外壳 + 内嵌 Vue 前端 + 按需下载的 sidecar 插件。

## 安装

从 [Releases](https://github.com/upchr/meow/releases) 下载：

| 文件 | 说明 |
|---|---|
| `meow-setup-<版本>.exe` | NSIS 安装版，带开始菜单与卸载项 |
| `meow-bare-<版本>.exe` | 免安装版，单个 exe 直接运行 |

要求 Windows 10 1809 及以上。安装包约 6 MB，**不含后端**。

## 第一次打开：后端未连接是正常的

::: tip 这是设计，不是安装失败
安装包里没有后端插件。没有后端就没有 `/api`，首页自然显示「后端未连接」。
按下面两步装完插件，前端会每 5 秒重试，**不用重启应用**。
:::

### 第一步：打开插件列表

设置 →「本机插件」。**插件源地址留空即可**——应用内置官方源，列表会直接加载插件清单（当前清单把插件条目标记为隐藏，列表可能为空，见下方提示）。

![设置 →「本机插件」：插件源这行用内置默认（标着「当前」），下面是已装插件与运行状态](/screenshots/pc-install.png)

只有三种情况才需要动这个地址：

- **自建 / 换镜像源**：填你的 `packages.json` 地址（`index.json` 是旧别名，仍兼容）
- **本机测试**：插件源手动填 `http://127.0.0.1:9000/packages.json`
- **没有网络**：点「粘贴 JSON」，把清单内容贴进去，直接变成 `file://` 源

### 第二步：安装「影视后端」

正常情况列表里直接有「影视后端」，点「下载」；**列表为空时**从 [Releases](https://github.com/upchr/meow/releases) 下载 `apiserver-<版本>.zip`，回到插件页点「导入本地包」安装。装完的流程：

1. 解压到 `%APPDATA%\com.meow.player\plugins\apiserver\`
2. 校验 SHA256，不匹配就删除并报错（不会装半个）
3. 自动启用并启动进程
4. 端口从 9979 开始协商，被占用就顺延到 9980…9985
5. 健康检查通过后首页自动恢复

## 插件清单里有什么

| 插件 | 作用 | 必需 | 大小量级 |
|---|---|---|---|
| 影视后端（`apiserver`） | 搜索 / 详情 / 播放 / 代理 | 是 | 约 48 MB |
| drpy 运行时 | 跑 `.js` 源，大型配置离不开 | 强烈建议 | 约 4 MB |
| 弹幕聚合（`danmu-api`） | 弹幕源从 1 个变 20+ | 否 | 约 10 MB |
| Node 运行时 | `danmu-api` 的依赖，列表里隐藏 | 跟随依赖自动装 | 约 30 MB |

装「弹幕聚合」时会**自动连带下载 Node 运行时**，总下载约 40 MB。

::: warning 插件列表是空的怎么办（已知问题）
当前官方清单把插件条目都标记成了隐藏，全新安装后「本机插件」列表可能不显示任何可下载项。
逃生口：从 [Releases](https://github.com/upchr/meow/releases) 下载 `apiserver-<版本>.zip`，
用插件页的「导入本地包」安装。drpy、弹幕聚合与 Node 条目同样待补，
可先自建源（见 [自建插件源](/ecosystem/plugin-source)）。
:::

## 改用别人的后端

不想在本机跑 JVM，可以连局域网里已有的后端：

设置 →「后端地址」→ 填 `http://192.0.2.10:30011`。

注意：

- 目标机器必须允许来自你电脑的访问（`APISERVER_BIND` 不能是 `127.0.0.1`）
- 如果那边设了 `MEOW_AUTH_TOKEN`，这里要一起填
- 切换后本机插件可以停用，省内存

## 离线 / 内网安装

两条通道，都需要先有插件 zip：

1. **粘贴 JSON**：把 `packages.json` 的清单内容贴进设置页，应用存成本地清单。
   这种模式没有可拼接的相对目录，清单里的 `url` 必须写**绝对地址**。
2. **导入本地包**：直接选 `.zip`。这条路径**完全不依赖插件源**，也不校验清单，
   只校验 zip 内的 manifest。

`packages.json` 的写法见 [自建插件源](/ecosystem/plugin-source)。

## 更新

- **应用本体**：设置 →「更新」→ 检查并安装；**更新源留空 = 内置官方源**，内网自建源也能填
- 应用启动后会自动检查一次，之后每 24 小时检查一次，有新版才提示；也可以随时手动检查
- **插件**：插件列表里远端版本高于本地时显示「可升级」，点一下替换
- **回滚**：升级后启动不起来会**自动回滚**——旧目录改名为 `.bak`，
  新版健康检查失败就把 `.bak` 改回来并重启旧版，不会出现「升个级反而没后端」

::: tip 卸载不删数据
插件卸载只删插件文件，`data/` 目录（`policy.json`、观看记录等）不动。
:::

## 常见问题

| 症状 | 处理 |
|---|---|
| 一直「后端未连接」 | 插件是否已下载并启用；端口 9979 是否被别的进程占用 |
| 显示已连接但插件列表是「未安装」 | 可能连到了别的后端（幽灵后端），先确认后端地址；生产安装包不会出现 |
| 下载插件校验失败 | 清单里的 `sha256` 与实际 zip 不一致，重新打包或换源 |
| 装完还是旧版本 | 插件目录残留，卸载后重装；确认 `enabled.json` 指向新目录 |
| 弹幕装了还是没多源 | `policy.json` 里的 `danmakuApi` 可能被之前手填的地址占着，清空让它自动填 |
| 应用启动慢 | 后端 JVM 冷启动 + 端口协商，属正常；插件健康检查超时是 45 秒 |

更多插件机制见 [插件与安装](/ecosystem/plugins)。

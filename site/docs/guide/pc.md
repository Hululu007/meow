# PC 桌面端

Windows 桌面应用，Tauri 2 外壳 + 内嵌 Vue 前端 + 按需下载的 sidecar 插件。

> 不确定装哪个？先看 [快速开始 · 路线选择](/guide/quick-start#路线选择)。

## 装好它

从 [Releases](https://github.com/upchr/meow/releases) 下载：

| 文件 | 说明 |
|---|---|
| `meow-setup-<版本>.exe` | NSIS 安装版，带开始菜单与卸载项 |
| `meow-bare-<版本>.exe` | 免安装版，单个 exe 直接运行 |

要求 Windows 10 1809 及以上。安装包约 6 MB，**不含后端**。

::: tip 第一次打开显示「后端未连接」是正常的
安装包里没有后端插件。按下面两步装完插件，前端会每 5 秒重试，**不用重启应用**。
:::

**第一步**：设置 →「本机插件」。**插件源地址留空即可**——应用内置官方源，列表会直接加载官方清单，正常点「下载」即可。

![设置 →「本机插件」：插件源这行用内置默认（标着「当前」），下面是已装插件与运行状态](/screenshots/pc-install.png)

只有三种情况才需要动这个地址：自建 / 换镜像源填你的 `packages.json` 地址；本机测试填 `http://127.0.0.1:9000/packages.json`；没有网络就点「粘贴 JSON」把清单内容贴进去（存成 `file://` 源）。

**第二步**：列表里直接有「影视后端」，点「下载」。装完自动解压、校验、启用、启动，端口从 9979 起协商，健康检查通过后首页自动恢复。
如果源包里用的是 `.js` 源，再把「drpy 运行时」也装上（同一列表，几 MB），否则那些站点会显示不可用。

::: details 清单拉取失败、列表为空时：离线安装

从 [Releases](https://github.com/upchr/meow/releases) 下载 `apiserver-<版本>.zip`，回插件页点「导入本地包」离线安装。这条路径**完全不依赖插件源**，只校验 zip 内的 manifest，清单拉取失败时照样能装。

也可以把 `packages.json` 的清单内容贴进设置页（「粘贴 JSON」）用本地清单——这种模式清单里的 `url` 必须写**绝对地址**；写法见 [自建插件源](/ecosystem/plugin-source)。

:::

## 装好之后

::: tip 接下来：导入源包
后端起来只是有了「播放器」，站点（搜索 / 详情 / 播放地址）来自源包；导入后首页才有内容。
步骤见 [导入源包](/guide/source-pack)。
:::

::: details 插件清单里有什么

体积以更新清单 `packages.json` 里的 `size` 为准，这里只给量级。

| 插件 | 作用 | 必需 | 大小量级 |
|---|---|---|---|
| 影视后端（`apiserver`） | 搜索 / 详情 / 播放 / 代理 | 是 | 约 31 MB |
| drpy 运行时 | 跑 `.js` 源，大型配置离不开 | 强烈建议 | 约 4 MB |
| 弹幕聚合（`danmu-api`） | 弹幕源从 1 个变 20+ | 否 | 约 10 MB |
| ffmpeg | 转码：片库和浏览器解不了的格式靠它 | 否 | 约 39 MB |
| Node 运行时 | `danmu-api` 的依赖 | 装弹幕聚合前先装 | 约 30 MB |

弹幕聚合依赖 Node 运行时，官方清单不会自动级联：先装「Node 运行时」再装「弹幕聚合」（合计约 40 MB）。ffmpeg 是独立插件，装完自动接到后端，不用手动填路径。更多机制见 [插件与安装](/ecosystem/plugins)。

:::

::: details 改用别人的后端（不在本机跑 JVM）

设置 →「后端地址」→ 填 `http://192.0.2.10:30011`。要点与 TV / Docker 一致（地址可达、令牌一致），见 [局域网访问与令牌](/guide/web-docker#局域网访问与令牌)。切换后本机插件可以停用，省内存。

:::

::: details 窗口与快捷键

- **无边框窗口**：左上角红黄绿三个按钮，红是关闭、黄是最小化、绿是最大化 / 还原；按住窗口空白处可以拖动，双击也能最大化 / 还原。窗口的大小和位置会自动记住。
- **Ctrl+F 直接搜索**：桌面应用里按 Ctrl+F 跳到搜索页；浏览器里打开 Web 版时仍是浏览器自带的页内查找。
- **关闭 = 收进托盘**：点关闭默认隐藏到托盘，点托盘图标恢复，托盘菜单里可真正退出。不想要就去 设置 →「桌面端行为」→ 关掉「关闭窗口时最小化到托盘」。

:::

## 出问题

| 症状 | 先查什么 |
|---|---|
| 一直「后端未连接」 | 插件是否已下载并启用；端口 9979 是否被别的进程占用 |
| 显示已连接但插件列表是「未安装」 | 可能连到了别的后端（幽灵后端），先确认后端地址；生产安装包不会出现 |
| 下载插件校验失败 | 清单里的 `sha256` 与实际 zip 不一致，重新打包或换源 |
| 装完还是旧版本 | 插件目录残留，卸载后重装；确认 `enabled.json` 指向新目录 |
| 弹幕装了还是没多源 | `policy.json` 里的 `danmakuApi` 可能被之前手填的地址占着，清空让它自动填 |
| 应用启动慢 | 后端 JVM 冷启动 + 端口协商，属正常；插件健康检查超时是 45 秒 |

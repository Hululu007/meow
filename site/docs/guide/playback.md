# 播放、弹幕与直播

这一页是日常使用说明：怎么找到片、怎么处理播不动、弹幕从哪来、直播和片库怎么用。

## 搜索与选源

首页是推荐位与分类；左上角搜索框点一下进搜索页。

搜索页分两态：

- **空闲态**：热播榜 + 最近搜索，点一下直接搜
- **结果态**：聚合结果，按源分组；返回键先回空闲态，再退出

聚合搜索的策略是**自适应预算**：给每个源一个超时预算，超时就跳过，
先返回已有结果，不让一个慢源拖死整页。结果会缓存一段时间。

搜索太多杂项时，可以在设置里配屏蔽词（解说、合集、混剪等），支持只降权不隐藏。

## 详情页

详情页会显示：

- 片名、海报、简介（太长可展开）
- 来自哪个源
- 线路与集数

::: tip 没有线路怎么办
说明这个源只有元数据没有播放源（豆瓣类原生源常见）。
页面底部会给「在其它源搜索《片名》」的出口，一键跳到搜索结果。
:::

## 播放

### 换线

播放失败时先换线，而不是先转码：

- 网络抖动 / 超时 → 自动换下一条线路
- 一条线路连续失败才换台 / 换源，不会因为单条死线跳走
- 手动换线：播放页「线路」

### 倍速与续播

- 0.5x–3x
- 1.25x 以上按带宽自动降档；实在跟不上会临时回 1x 并提示
- 换集或换线路后不会从上一集的位置开始（进度按集隔离）
- 退出再进从上次位置继续

### 选集与连播

- 选集列表自动定位当前集
- 超过 100 集会分段
- 连播倒计时在全屏里也能看到、能取消
- 播放到半分钟左右开始预取下一集地址，切换几乎不用等

### 字幕

- 外挂 SRT / ASS
- HLS 内嵌字幕
- 手动加载本地字幕文件

### 画中画与投屏

- 画中画：浏览器 / 桌面端支持时可用
- DLNA：同一局域网内的电视 / 音箱，播放页「投屏」

### 片头尾与中插

可在设置里配片头片尾时长，播放时自动跳过；中插按规则匹配。
配置项按源或全局生效。

## 弹幕

### 来源顺序

默认顺序是 **爱奇艺 → 腾讯 → 自建弹幕服务 → 聚合兜底**，同一集并发抢占、先到先用，
不是串行依次尝试。

设置里可以改成「弹幕 API 优先」，或直接只保留自建聚合服务。
如果自建服务排在第一位，首屏等待预算会从 6 秒放宽到 10 秒。

### 手动搜索

播放页「搜索弹幕」可以按片名 / 集数手动找。选中来源后会自动定位到正在看的那一集。

### 显示

| 项 | 可调 |
|---|---|
| 屏蔽词 | 正则或关键词 |
| 密度 | 同屏条数上限 |
| 透明度 | 0–100% |
| 字号 | 小 / 中 / 大 |
| 速度 | 滚动速度 |
| 颜色 | 部分源保留原色（如腾讯彩色弹幕） |

### 缓存

- 弹幕按集缓存在本地，下次直接读
- 缓存有上限，超出后清理最久没看的；正在播的那一集永远保留
- 快到片尾时预取下一集，进详情页会先抓第 1 集
- 片尾预取开关、提前量、缓存上限都在设置里

::: tip 弹幕不动 / 整屏消失
缓冲时弹幕会跟着暂停，恢复后继续，不会清屏重打。
如果仍然异常，先确认播放器时间在走；时间不动时弹幕不会动，这是预期行为。
:::

## 直播

数据来自两处：站点配置里的直播表，以及 IPTV 的 m3u / txt。

操作：

- 进页面直接全屏播放
- 遥控器 OK 呼出「分类 - 台」面板，左右分栏各自滚动
- 上下换台，左右切线路
- 一条线路失败会先把同台的其他线路试完，再换台

公共 IPTV 源经常整条失效，属上游问题。想稳定就用自己的 m3u。

## 片库

支持三种来源：

| 类型 | 说明 |
|---|---|
| WebDAV | 远程目录，适合 NAS |
| 本地 | 设备上的文件夹 |
| SMB | Windows 共享 |

片库能力：

- Range 直连，拖动进度条不用等转码
- 不支持的格式按需转 HLS
- 海报刮削（本地 nfo 优先，缺的再查在线元数据）
- 按目录浏览，返回键逐级退

## 离线缓存

- 单集或整季缓存
- 断点续传
- 离线优先：有缓存时不再请求源站
- 缓存条目可在设置里清理

::: warning 缓存不等于永久
源站地址常绑客户端 IP 且几分钟过期。已缓存的媒体文件不受影响，
但重新拉取清单时可能失败，表现为「有缓存能看，新集拉不到」。
:::

## 收藏、历史与跨端

- 收藏、观看进度、历史、观看统计、偏好在端内保存
- 配了跨端通道后，这些状态在 Web / PC / TV 之间共享
- WebDAV 可做快照式同步与备份（不是实时同步，需要手动触发或按计划）

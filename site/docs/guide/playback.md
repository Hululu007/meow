# 播放与弹幕

这一页只讲「已经点开一部片之后」的事：播放器怎么操作，弹幕从哪来、怎么调、怎么缓存。

找片、搜索、详情页与直播见 [点播与直播](/guide/vod-live)；自己的文件、离线下载与缓存见 [片库与缓存](/guide/library)；想让 AI 用人话解释播放失败见 [AI 助手](/guide/ai)。

## 打开一部片之后

点开一集就自动起播。点一下画面是播放 / 暂停，同时唤出底部控制栏。

控制栏 5 秒没有操作会自己收起；选集、线路、弹幕设置这些面板开着时不会收，免得你还没选完它就跑了。

电视上按向下键唤出控制栏，返回键从最上面一层开始逐层退出。

## 底栏上有什么

| 位置 | 能做什么 |
|---|---|
| 播放键 | 播放 / 暂停 |
| 进度条 | 拖动跳转到任意位置 |
| 音量 | 静音切换、拖动改音量（窄屏上不显示，靠手机音量键） |
| 上一集 / 下一集 / 选集 | 切到相邻集、打开集号网格 |
| 线路 | 打开线路面板，列出所有线路与各自集数 |
| 片头 / 片尾 | 把当前位置记为片头结束点 / 片尾开始点 |
| 「弹」 | 弹幕总开关 |
| 放大镜 | 手动搜索弹幕 |
| 倍速 | 0.5x – 3x 八档 |
| 全屏 / 重播 / 刷新 | 全屏切换、从头重播、重新加载当前地址 |

## 「更多」里有什么

| 位置 | 能做什么 |
|---|---|
| 选集 / 线路 / 片头标记 / 片尾标记 / 搜索弹幕 | 屏幕不够宽时从底栏收进来的入口 |
| 画中画 | 浏览器支持时出现，再点一次退出 |
| 字幕 | 循环切换字幕轨 |
| 弹幕设置 | 打开弹幕调节面板 |
| 投屏到电视 | 搜索局域网内的 DLNA 设备（这一集有可直接播放的地址时才出现） |
| 播放信息 | 码率、缓冲、线路等排障数据 |
| 睡眠定时 | 15 / 30 / 60 / 90 分钟，到点暂停播放 |
| 下载到本机 / 下载整季 | 见 [片库与缓存](/guide/library) |

## 回到上次的位置

同一集退出再进，起播后画面下方会提示「已从 12:34 继续播放」，8 秒后自动消失。片源自带起播点时提示变成「已跳到 12:34 开始播放」。

点提示条上的「从头开始」，会清掉这部片已存的进度，从 0 开始；点 ✕ 只是关掉提示，不影响进度。

| 情况 | 行为 |
|---|---|
| 看的时长不足 5 秒 | 不提示，从头开始 |
| 距结尾 10 秒内 | 不记进度，下次进也不会跳到片尾 |
| 一集播完 | 清掉记录，下次从头开始 |
| 换到别的集 | 不套用上一集的秒数 |
| 换线路 | 先存进度，新线路里对应的那一集接着播 |

## 换一集与连播

底栏「选集」打开集号网格，会自动滚到当前集并高亮；每个集号右上角的小圆点表示自上次观看后新增的集。面板顶部显示总集数和当前第几集，点集号立即切换。

一集播完后的行为在设置 →「播放」→「自动连播」里选：

| 选项 | 播完后 |
|---|---|
| 立即播放 | 直接进下一集 |
| 倒计时 | 显示倒计时浮层，默认 5 秒，可改 3 / 5 / 8 / 10 / 15 秒 |
| 不自动 | 停在片尾，等你自己选 |

倒计时浮层上有「立即播放」和「取消」，全屏里也能点到。播过 30 秒后会预取下一集地址，切集时少等一会儿。

## 倍速

倍速菜单有 0.5x、0.75x、1x、1.25x、1.5x、2x、2.5x、3x 共八档。选择会记住，切集和下次打开仍然生效。

高倍速下，多码率片源会自动压低档位，优先保证不卡。连续缓冲且缓冲见底时会临时回到 1x，并提示「网络跟不上，已临时恢复 1x」；缓冲恢复到 20 秒后自动回到你选的倍速，并提示「已恢复 2x」。

弹幕速度跟着倍速一起变。

## 跳过片头片尾

默认不跳。要在设置 →「播放」里把「跳过片头 / 跳过片尾」设成 15 / 30 / 45 / 60 / 90 / 120 秒，才会按固定秒数跳。「跳过前倒计时」决定提示条上等多久再自动跳，可选立即跳或 3 / 5 / 10 / 15 秒，默认 5 秒。

进入片头或片尾区间时，右下角出现「跳过片头 → 0:45」或「跳过片尾 → 21:30」，带倒计时环：到点自动跳，点一下立即跳，点「取消本次跳过」这次不跳。

想按剧精确：播到片头结束点，点底栏「片头」；播到片尾开始点，点「片尾」；在标记位置附近再点一次取消标记。标记按剧记住，换集仍生效。

优先级是：手动标记 > 片源自带 > 设置里的默认秒数。片中的插广告默认不跳，要跳得在设置 →「播放」里单独打开「跳过中插广告」。

## 字幕

片源带外挂字幕时会自动显示第一份能用的，SRT / ASS 也能直接显示。

有字幕轨时，「更多 → 字幕」可以循环切换：关 → 第 1 条 → 第 2 条 → 关，按钮上会显示当前状态。

字幕只来自片源，不能在本机选字幕文件；片源没给就没有字幕入口。

## 画中画与投屏

画中画在「更多 → 画中画」，浏览器支持时才出现；再点一次退出。

投屏在「更多 → 投屏到电视」，会搜索同一局域网里的 DLNA 设备，最多约 3 秒。连上后本机自动暂停，电视开始播。

地址会经本机后端转一道，电视不用直连源站。找不到设备时，先确认电视和这台设备在同一个局域网，并且电视开了投屏 / DLNA。

## 播不动时换线路

播不出来先等自动处理：网络类失败会自动换下一条没试过的线路，这时会看到「正在尝试线路「B」…」和一条「线路「A」不可用，已切到「B」」的提示。编码或容器浏览器解不了时，会先尝试转码；转码不可用再换线。

手动换：底栏线路名（窄屏在「更多 → 线路」）打开面板，列出所有线路和各自的集数，选中即切。

换线会尽量停在同一集并保留播放进度：先按集名找，找不到再按同一位置找，都没有才回第 1 集。

全部线路都失败才会停在错误页，可以点「重试」或「换个线路」；电视上还有「用原生播放器打开」。手动选过的线路会被记住，下次同片优先用它。

## 弹幕从哪来

自动抓取会同时问内置直连（爱奇艺、腾讯）和聚合服务，谁先返回非空结果就用谁。控制栏顶部的标题下方会显示这一集的弹幕条数和来源。

设置 →「弹幕」→ 来源里可以选「内置直连优先」或「弹幕 API 优先」：前者首屏最多等 6 秒，后者 10 秒。聚合这一档即使没填自建地址，也会试内置镜像；填了自建地址就只用自建的。关掉「腾讯自动抓取」后，腾讯只出现在手动搜索里。

其余源会在后台继续跑；结果明显更全（至少 1.2 倍）就写进缓存，下次打开这一集时用更全的那份。

当前这一集也会在首屏成功约 12 秒后再查一次：更全的结果如果正好赶上安全时机（刚开始播 15 秒内，或你刚拖过进度条）会立刻换上，提示「已切换到更全的弹幕源」；不赶巧就等你下次拖动进度条时再生效，面板里写着「更全的 N 条待应用（seek 后生效）」。

所有源都没结果时，顶部显示「弹幕加载失败（重试中…）」，30 秒后自动再试一次。

## 手动找弹幕

自动抓不到时，点底栏的放大镜（窄屏在「更多 → 搜索弹幕」），输入片名后点「搜索」。

结果按来源分组：上方胶囊可以按平台筛选，每行左侧的来源标签分两种——「直连」和「danmu_api」，用不同颜色标出。每行给出标题和站点，能解析出集数时还会带一个集数徽标。

点一条就立即使用这份弹幕，并从当前播放进度继续，不会回到片头。切下一集时会优先沿用同一来源的同集结果；找不到就恢复自动抓取并提示。

想回到自动：弹幕设置面板底部的「恢复自动」。

## 弹幕样式

底栏「弹」是开关；「更多 → 弹幕设置」打开调节面板。

| 想调什么 | 可选 |
|---|---|
| 密度 | 稀疏 / 标准 / 密集 |
| 透明度 | 20%–100% |
| 字号 | 70%–160% |
| 滚动时长 | 6–20 秒 |
| 显示区域 | 画面的 30%–100% 高度 |
| 屏蔽词 | 设置 →「弹幕」，逗号或换行分隔 |

三档密度对应 18 / 12 / 9 秒滚动和 55% / 70% / 85% 区域；手动改过滚动时长或显示区域后，密度会显示为「自定义」。颜色沿用弹幕源里的原色，彩色弹幕会保留；纯符号和 1.5 秒内重复刷屏的弹幕会自动过滤。

## 弹幕缓存

打开一集先读浏览器本地缓存：有就直接显示，断网也能看；没有才去抓，抓到后按集存下来。

| 缓存 | 保留 | 上限 |
|---|---|---|
| 浏览器本地 | 30 天 | 最多 300 集，单集超过约 2MB 不写入，超了淘汰最早写入的 |
| 后端磁盘 | 30 天 | 断网时 Web 部署够不着，浏览器这份才是离线关键 |

快到片尾时会预抓下一集，触发点是「片尾标记或总时长」减去提前量，默认提前 180 秒；开关和秒数在设置 →「弹幕」里改。

清理：设置 →「弹幕」→「浏览器弹幕缓存」点「清除」；后端那份在设置 →「存储」→「后端弹幕缓存」，可以「清过期」或「全清」。

## 出问题先看什么

| 现象 | 先看 |
|---|---|
| 一直转圈 / 黑屏 | 顶部有没有「正在尝试线路「X」…」，等自动换线；停在错误页就点「重试」或「换个线路」 |
| 有画面没弹幕 | 看控制栏顶部的条数；提示「弹幕加载失败（重试中…）」时等 30 秒自动重试，仍是 0 条就手动搜索 |
| 弹幕突然不动 | 画面是不是在缓冲或暂停；时间不走弹幕不走，恢复播放后会继续 |
| 弹幕太多太吵 | 「更多 → 弹幕设置」调密度，或在设置 →「弹幕」里加屏蔽词 |
| 投屏找不到设备 | 电视和本机是否同一局域网，电视的 DLNA 是否打开 |
| 字幕不显示 | 片源本身是否带字幕；有字幕轨时在「更多 → 字幕」里切换 |
| 播着播着掉到 1x | 看「更多 → 播放信息」里的缓冲，通常是带宽跟不上 |

播放失败页上会直接给出原因判断（比如网络、解码、源站失效），并给出一条可执行建议；配了模型时还会多补一句人话解释，点「按建议处理」就会照着做。

播放页上不显示 AI 悬浮面板（免得挡住控件），想追问得先退出这一集，再到顶栏「AI」或底部导航的「AI」进去问。

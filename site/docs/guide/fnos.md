# 飞牛 fnOS

把 Web 版打成 fnOS 原生套件（fpk），在应用中心安装与升级，不用自己维护 compose。

## 安装

### 应用中心

在飞牛应用中心添加应用源后搜索「猫窝」，按机器架构自动匹配 x86 / arm 包。

### 手动安装 fpk

从 [Releases](https://github.com/upchr/meow/releases) 下载对应架构：

| 文件 | 架构 |
|---|---|
| `meow_<版本>_x86.fpk` | x86_64 |
| `meow_<版本>_arm.fpk` | arm64 |

应用中心 → 手动安装 → 选择 fpk。

::: tip 装不上的两种情况
- **架构不对**：x86 机器装 arm 包会直接拒绝
- **版本低于已装版本**：应用中心不允许降级，先卸载再装
:::

安装向导里的端口是**数值范围校验**（1024–65535），填字符串或超范围会卡在下一步。

## 装完之后

- 服务由应用中心托管，开机自启
- 从应用中心入口打开，走网关子路径（不需要记端口）
- 自带 Node 22 运行时，弹幕插件装完即用
- 升级应用不会覆盖应用数据目录里的弹幕设置

## 弹幕

fnOS 版内置弹幕插件，复用应用中心的 Node 运行时，不额外打包一份。

- 弹幕服务崩溃只影响弹幕，播放与搜索照常
- 未安装 Node 时会自动跳过插件，播放不受影响
- 插件配置存在应用数据目录，升级不覆盖

## 应用内更新

设置 →「应用更新」可以检查并安装新版本，不用回应用中心。

- 更新源地址可在设置页修改，内网自建源也能用
- 升级会自动重启服务，页面短暂断开后自动回到新版本
- 读不到应用所在存储卷时会拒绝升级，避免装到错误分区

## 排障

| 症状 | 处理 |
|---|---|
| 页面白屏 | 必须通过应用中心网关入口打开；子路径部署对 `base` 有要求 |
| 接口全挂但外壳能开 | 后端进程没起来；应用中心里重启一次 |
| 弹幕不可用 | 应用中心里确认 Node 22 运行时已安装 |
| 端口冲突 | 安装向导里改端口；范围 1024–65535 |
| 升级后版本没变 | 应用内更新与商店可能短暂不同步，回应用中心检查 |

# 片库与直播

两个「不依赖源包」的入口：自己的片库文件，和 IPTV 直播源。

## 片库

支持的存储类型：

| 类型 | 适合 | 说明 |
|---|---|---|
| **WebDAV** | NAS、网盘 | 入口最完整，推荐 |
| **本地** | 本机硬盘 | 桌面端与 TV 可用 |
| **SMB** | Windows 共享 | 部分版本支持，见添加页的类型选择 |

### 添加

片库页 →「添加片库」：

```
类型     WebDAV
地址     http://192.0.2.10:5005/dav/视频
用户名   （可选）
密码     （可选）
```

地址要填到**目录级**，不要填到具体文件。带子路径的 WebDAV 服务（群晖
`/dav/`、Nextcloud `/remote.php/dav/files/user/`）要写全。

::: tip 先确认能访问
在浏览器里打开这个地址，能出目录列表或要求登录，说明路径对了。
片库页报「连不上」时，九成是路径少了一层或端口不对。
:::

### 目录结构

按「剧名 / 季 / 集」组织最省心：

```
视频/
├── 某部电影 (2024)/
│   └── 某部电影.2024.1080p.mkv
└── 某部剧/
    ├── Season 1/
    │   ├── S01E01.mkv
    │   └── S01E02.mkv
    └── Season 2/
```

文件名里带年份、季集号、分辨率，刮削匹配率会明显提高。

### 刮削

海报与元数据的顺序：

1. **本地 `tvshow.nfo` / `movie.nfo` 优先**（你整理好的，不再覆盖）
2. 缺的再查在线元数据
3. 都不匹配时可以在片库详情里**手工指定**片名或 ID

匹配错了可以「解除匹配」，重新指定。

### 播放方式

- **Range 直连**：格式支持时直接读远端文件，拖动进度条不用等转码
- **按需转 HLS**：不支持的容器/编码由后端切片转码，起播慢一些

优先级是直连优先。转码是否可用取决于后端有没有 ffmpeg
（Docker 镜像自带；PC 需要 `ffmpeg` 插件）。

## 离线缓存

- **单集**或**整季**缓存
- 断点续传：中断后从断点继续
- **离线优先**：有缓存时不再请求源站

缓存在 `data/cache/`，体积大，备份时可以排除。

::: warning 缓存与源站是两回事
已缓存的媒体文件不受源站失效影响；但重新拉清单仍需要源站可达。
表现为「旧集能看，新集拉不到」。
:::

## 直播

直播有两个来源：

| 来源 | 从哪来 |
|---|---|
| **站点直播表** | 源包 `config.json` 的 `lives` 字段，导入后自动出现 |
| **自己添加的 IPTV 源** | 直播页「添加源」，填 m3u / txt 地址 |

### 添加 IPTV 源

直播页 → 添加源 → 填 `http(s)` 开头的地址：

```
https://example.com/iptv.m3u
https://example.com/channels.txt
```

- `.m3u` 按 `#EXTINF` 解析分组与台标
- `.txt` 按 `频道名,地址` 逐行解析
- 填完会立即探测一次，拿不到的源会标失败

::: tip 源要能被电视访问到
填 `127.0.0.1` 在电视上指电视自己。局域网地址要写主机的实际 IP。
:::

### 操作

| 场景 | 按键 |
|---|---|
| 进页面 | 直接全屏播放上次的台 |
| 呼出频道面板 | 遥控器 OK |
| 换台 | 上 / 下 |
| 切线路 | 左 / 右 |
| 呼出控制栏 | 遥控器菜单键 |
| 返回 | 逐层退回列表 |

频道面板是「分类 - 台」左右分栏，两栏各自滚动。

### 坏台与坏线

- 一条线路失败，会先把同台的**其他线路试完**，再换台
- 所有线路都失败才自动跳到下一个台
- `m3u` 里同一个台有多个地址时，它们会被当成线路池

### EPG

当前不做节目单。公共 EPG 源时效性太差，投入产出比不高。

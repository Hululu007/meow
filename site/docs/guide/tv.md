# TV / 投影仪

Android TV 客户端是一个 WebView 壳 + 端上 ExoPlayer + 本地 jar 执行环境。
它比 Web 版多做了三件事：遥控器导航、端内网关、`DexClassLoader` 直接跑源。

## 安装

| 方式 | 步骤 |
|---|---|
| U 盘 | 把 `meow-TV-<版本>.apk` 拷到 U 盘，用电视的文件管理器安装 |
| adb | `adb install -r meow-TV-<版本>.apk` |
| 应用市场 | 本项目不投应用市场，只提供 APK |

最低 Android 8.0（API 26）。投影仪常见的 Android 9 / armeabi-v7a 能装，但见页尾的限制。

## 两种运行方式

TV 可以完全不依赖电脑（本机执行），也可以连局域网里已有的后端。

### 本机执行（推荐，零依赖）

1. 设置 →「本机执行」→「配置地址」
2. 填入源包 `config.json` 的 URL
3. 返回首页等待站点加载

要求：

- **源包必须是 dex 形态 jar**（ZIP 内含 `classes.dex`），class 形态在 Android 上加载不了
- 每个 `csp_` 站点要带 `jar` 字段，或顶层 `spider` 可用
- 配置里的地址必须电视能访问到（不要写 `127.0.0.1`）

### 连后端

电视只当播放器，搜索/详情/播放地址都走后端：

1. 先在局域网机器上起好 [Docker 后端](/guide/web-docker) 或 PC 后端
2. 设置 →「后端地址」→ 填 `http://<主机IP>:30011`（PC 后端默认 9979）
3. 如果后端设了令牌，一起填

这种模式对电视性能要求最低，源包只需维护一份。

## 扫码配置

手机扫码可以把**后端地址 + 配置地址**一次推给电视，不用在电视上敲遥控器。

入口在设置页的「扫码推送」。手机打开页面后：

- 页面显示当前访问令牌，需要时手填
- 推送后电视自动重载配置，不用重启应用

## 遥控器操作

| 场景 | 按键 | 动作 |
|---|---|---|
| 首页 / 列表 | 方向键 | 移动焦点，长按可连发 |
| 首页 / 列表 | OK | 进入 |
| 播放页 | OK | 呼出控制栏 |
| 播放页 | 菜单键 | 随时唤出控制栏 |
| 播放页 | 上 / 下 | 切集；直播时换台 |
| 播放页 | 左 / 右 | 切换线路 |
| 播放页 | 上键（长按） | 静音 / 取消静音 |
| 直播页 | OK | 呼出「分类 - 台」面板，左右分栏各自滚动 |
| 任意页 | 返回 | 逐层返回：搜索页先回搜索首页、片库先回上一级目录 |
| 滑块（音量/透明度） | 左 / 右 | 调值 |
| 倍速 / 弹幕 / 投屏面板 | 返回 | 关闭面板 |

焦点框是白边 + 主题色描边 + 外发光，跨主题保持一致。

## 运行时模块

TV 支持像插件一样安装运行时模块（Fongmi 形态）：独立 APK，通过 `DexClassLoader`
加载，跑在单独的 `:node` 进程里。

| 模块 | 作用 |
|---|---|
| Node 运行时 | 给 drpy 的 `.js` 源与 `danmu_api` 提供执行环境 |
| 弹幕聚合 | 弹幕源从 1 个变 20+，不依赖电脑 |

安装：

1. 设置 →「运行时模块」
2. 选择对应 ABI 的模块下载（arm64-v8a / armeabi-v7a / x86_64）
3. 安装后应用会自动重启并加载

模块走 `packages.json` 清单校验 SHA256，按 `platform` 匹配 ABI。
细节见 [TV 运行时模块](/ecosystem/runtime-module)。

## 端内网关

TV 壳里带一个本地 HTTP 网关（默认 41 条路由），把 `spider` 调用、代理播放、
搜索聚合都收敛到端内。它的作用是让 WebView 里的前端以为自己在跟一个普通后端说话。

网关只在应用进程内监听，不对外暴露；退出应用即停止。

## 排障

| 症状 | 先查什么 |
|---|---|
| 装了打不开 / 闪退 | 架构是否匹配（投影仪常见 armeabi-v7a）；Android 版本是否 ≥ 8.0 |
| 配置导入成功但站点全红 | jar 是不是 dex 形态；站点有没有 `jar` 字段 |
| 一直「正在加载」 | 配置地址电视能不能访问；换手机热点验证一次 |
| 能搜不能播 | 源站地址绑客户端 IP 或已过期，换线路试试 |
| 遥控器进不了地址输入框 | 改用扫码推送，或先用后端模式在手机/电脑上配置 |
| 播放卡顿 | 电视解码能力有限，降低画质或换线路；见 [播放与弹幕](/guide/playback) |

::: warning 投影仪（armeabi-v7a）的已知问题
低端 32 位设备上，聚合搜索并发过高可能把进程打崩。
这不是配置问题，属于端上资源限制，详见 [已知限制](/reference/limits)。
:::

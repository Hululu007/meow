# 术语表

文档里反复出现的词，一句话解释。

## 内容源相关

| 词 | 含义 |
|---|---|
| **源包（Source Pack）** | `config.json` + spider jar 的组合，决定你能搜到什么 |
| **spider** | 爬虫实现，通常是一个 jar；也指配置里指向 jar 的字段 |
| **jar** | Java 归档包。JVM 端要 **class 形态**，TV 端要 **dex 形态** |
| **class / dex** | 两种字节码格式。前者给 JVM，后者给 Android 的 ART |
| **`csp_` 站点** | `api` 以 `csp_` 开头的站点，由 spider jar 处理 |
| **`ext`** | 传给 spider 的扩展参数，同一个 jar 靠不同 ext 出不同站点 |
| **`key`** | 站点唯一标识，同名 jar 多实例时必须不重复 |
| **线路** | 同一部片的播放地址分支，通常对应不同 CDN 或清晰度 |
| **`parse=1`** | 播放地址不是媒体直链，需要先过解析器 |
| **解析器（parse）** | 把分享页地址转成真实媒体地址的服务 |
| **`flag`** | 解析器的适用范围，限定只对某些线路生效 |
| **`type: 1`（CMS）** | 苹果 CMS 协议，后端直接调接口，不需要 jar |
| **drpy** | 用 JavaScript 写的一种源，靠 Node 运行时执行 |
| **多仓索引** | `{"urls":[...]}` 形式的配置，把多个仓串起来 |

## 生态与协议

| 词 | 含义 |
|---|---|
| **CatVod** | 一类影视客户端的配置协议，`/config.json` 九字段来自它 |
| **TVBox / Fongmi** | 同生态的客户端，配置与 jar 格式互通 |
| **fnpack** | 插件源清单文件，列出可下载的插件与 SHA256 |
| **manifest** | 插件自己的描述文件，声明怎么启动、怎么判活 |
| **sidecar** | 随主进程启动的独立进程，PC 的后端就是 |
| **DexClassLoader** | Android 动态加载 dex 的机制，TV 端靠它跑 jar |
| **端内网关** | 跑在 TV 应用进程里的本地 HTTP 服务，把前端请求转给 spider |
| **MCP** | 一种让外部工具（脚本 / AI）调用客户端能力的协议 |

## 技术与格式

| 词 | 含义 |
|---|---|
| **HLS / m3u8** | 分片式流媒体，最常见；清单里是 `.ts` 分片 |
| **DASH** | 另一种分片流，多用于高码率 |
| **Range** | HTTP 分段读取，片库直连靠它实现拖动进度条 |
| **转码 / 转 HLS** | 后端用 ffmpeg 把不支持的格式切片，起播更慢 |
| **DoH** | DNS over HTTPS，加密解析，用于绕过污染 |
| **CORS** | 浏览器的跨域限制，Web 版部署时的常见问题 |
| **公开壳** | 不含源包的仓库与安装包，导入源包后才有内容 |

## 易混的三组

| 容易混 | 区别 |
|---|---|
| 源包 vs 插件 | 源包给「内容」，插件给「能力」（后端、drpy、弹幕服务） |
| 站点 vs 源 | 一个源包里有多个站点；「源」也常指单个站点 |
| 收藏 vs 片库 | 收藏是源里的片；片库是你自己的文件 |

# 全 JVM 加载器验证：Java 兼容性 + 实测（2026-11-24，`feat/fongmi-loaders`）

> 目标：验证"不给各端装 node/py 插件，改为 JVM 内跑 js/py 源"技术上是否可行。
> 结论先说：**JS 可行（GraalJS 21.3.0，Java 8+）、Python 在 Java 9 上不可行（GraalPy 最低 Java 21）**。

## 一、Java 版本兼容性（按 class major 实查）

| 组件 | 版本 | class major | 最低 Java | Java 9 可用？ |
|---|---|---|---|---|
| **GraalJS** | **21.3.0** | **52** | **Java 8** | ✅ |
| GraalJS | 22.3.1 | 55 | Java 11 | ❌ |
| GraalPy（最早版） | 24.1.0 | polyglot 55 / **truffle 65** | **Java 21** | ❌ |

判据：major 52=Java8, 55=Java11, 61=Java17, 65=Java21（用 `javap -verbose` 读真实 class）。

**要兼容 Java 9，只能用 GraalJS 21.3.0；GraalPy 无解**（最早 24.1.0 就要求 Java 21）。

## 二、GraalJS 21.3.0 实测（Java 8 JVM 上跑）

环境：本机 `/o/tools/jdk1.8.0_162` + `graal21-libs/`（js/regex/truffle-api/graal-sdk/icu4j 全 major=52）。
探针：`tmp/fongmi-verify/GraalJsProbe.java`（Context.newBuilder("js").allowAllAccess(true)），
注入 `print`（→ Java stdout）、`req`（→ HttpURLConnection 返回 `{code,content,headers}` Map）。

用真实脚本 `jumi.js` 实测：

```
script loaded: true
methods: init,homeContent,searchContent,detailContent,playerContent
[js] >>> jumi fetch start: https://gimytw.cc/search?q=斗破&page=1
[js] >>> jumi fetch done: ... status=200 len=50489
search result len=2042
head={list: [{vod_id: "201884754", vod_name: "斗破蒼穹/斗破苍穹", ...}, ...]}
```

**结论：JS 源在 JVM 上完全可行**——脚本加载、`var spider={__jsEvalReturn}` 导出发现、
`print`、`req` 网络、search 返回数据，全通。而且是在 **Java 8** 上跑的，Java 9+ 更没问题。

注意：`allowAllAccess(true)` + 解释执行（无 JIT 警告）——性能是解释模式，后面可评估。

## 三、GraalPy 实测结论（Java 9 不可行）

- GraalPy 最早公开版本 24.1.0；其 truffle-api class major=65（Java 21）。
- 在 Java 8/9/11/17 上加载直接 `UnsupportedClassVersionError`。
- **如果放弃 Java 9 兼容、升到 Java 21**，GraalPy 可评估，但还要解决：
  - Python 标准库/三方包（requests/bs4/lxml/pycryptodome）在 GraalPy 的安装路径（`graalpy-maven-plugin` 管虚拟环境）
  - 这批脚本依赖的 `base.spider` 契约（见 `fongmi-loaders-验证-2026-11-24.md`）
  - 性能与内存（GraalPy 比 CPython 慢、启动重）

## 四、落地建议（若采用全 JVM 方案）

| 源类型 | Java 9 目标 | 做法 |
|---|---|---|
| CMS | ✅ | 现有 CmsSource 不动 |
| jar(csp_) | ✅ | 现有 DexClassLoader 不动 |
| **JS** | ✅ | 后端加 GraalJS 21.3.0 依赖，新增 `ScriptSource` 分派：api 含 `.js` → Graal Context 执行；注入 `req/pdfh/print` 全局（我们 drpy host.js 已有等价实现，可照抄） |
| **Python** | ❌ | Java 9 下**只能保留外挂 pyrt**；或升 Java 21 上 GraalPy（另一个专项） |

**关键点**：JS 这块全 JVM 化是可行的、且能兼容 Java 9；Python 是硬门槛，Java 9 做不到。
所以"完全去掉插件"在 Java 9 目标下**只能去掉 Node/drpy（JS 用 GraalJS 内嵌），去不掉 pyrt**。

## 五、复现命令

```bash
cd .worktree/fongmi-loaders/tmp/fongmi-verify
# 依赖（GraalJS 21.3.0，全 major=52）
mvn -q -f pom21.xml dependency:copy-dependencies -DoutputDirectory=graal21-libs
CP=$(ls graal21-libs/*.jar | tr '\n' ';')
/o/tools/jdk1.8.0_162/bin/javac -encoding UTF-8 -cp "$CP" GraalJsProbe.java
/o/tools/jdk1.8.0_162/bin/java -Dpolyglot.engine.WarnInterpreterOnly=false \
  -cp ".;$CP" GraalJsProbe <jumi.js>
# 预期：script loaded: true / methods 5 个 / search 返回斗破苍穹数据
```

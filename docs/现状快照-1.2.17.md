### 首页续播卡规则（易踩，单列）
- 只认 **24 小时内**（按 `ep_at`）且 `pos > 30s`、离结尾 `> 60s` 的最近一条
- 元数据（集名/站点 + 年份/地区/状态）在左栏一行；右栏只放简介 + 导演/主演
- 后端进度通道只有 8 个字段（无片名/封面）：占位条目会用 detail 补名/补图并写回历史
- TV：海报与片名用 `data-tv-skip` 不参与移焦，只留「继续播放 / 详情」两个焦点
- 外观 → 「首页续播卡」可整体关闭（`prefs.homeHero`）

### TV / 投影

## 4. 已知问题 / 待办

1. **播放/直播页的红黄绿仍在右上**：为避开播放器左上返回键的刻意取舍，与首页不一致
2. **投影仪无真机**：960×540 为 `data-form=tv-large` 模拟；Chromium 66 的 legacy 降级未截图复核
3. **iPhone Safari** 未验证（详情页取色与玻璃浮层性能）
4. **Inter 未随包分发**：`local('Inter')`，没装字体的机器回退系统字体
5. **PC 贴靠布局**未做（需要 `HTMAXBUTTON`，会让圆点失去 hover 字形）
6. **B7 调试端口**有后端开关，无设置页 UI
7. **历史里有一条测试条目**（我的有罪之人 / Douban）：已标为看完，不再占续播卡；后端进度通道无 DELETE，只能在历史页手动删
8. **6 列 + 16:9**：两整行海报在几何上放不下（MuMu 两行 ≈646px > 可用 488px），无 hero 时只能露到第二行约 60%

## 5. 升级指引

- **PC 壳**：设置 → 更新，或静默 `meow-setup-<ver>.exe /S /D=O:\tools\猫窝`
- **PC 插件**：设置 → 本机插件 → 对应插件的「升级」
- **TV**：应用内更新（读 packages.json）
- **fnOS / OECT**：应用中心内更新（读 FnDepot / fpk-updates），或应用内「检查更新」
